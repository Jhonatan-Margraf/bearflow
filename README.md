## Sobre

Site institucional da **BearFlow**, negócio de desenvolvimento web focado em pequenas e médias empresas de Toledo (PR) e região. Apresenta os serviços oferecidos — sites, sistemas e aplicativos sob medida — e serve como vitrine de projetos entregues.

---

## Stack técnica

- **Vite** — build tool e dev server
- **React** + **TypeScript**
- **shadcn/ui** — componentes de interface
- **Tailwind CSS** — estilização

---

## Rodando localmente

Pré-requisito: Node.js e npm instalados ([recomendado via nvm](https://github.com/nvm-sh/nvm#installing-and-updating))

```bash
# Clone o repositório
git clone <URL_DO_REPOSITORIO>
cd bearflow

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

O site estará disponível em `http://localhost:5173` (ou a porta indicada no terminal).

### Build de produção

```bash
npm run build
```

Os arquivos otimizados serão gerados na pasta `dist/`.

## Deploy
